How to read the colours

  • Teal, purple and gold model names indicate hosted decision, local and reasoning-disabled LLM configurations.

  • Cost markers ● / ◆ mean reported amounts / captured tariff estimates. “+ ?” means charges are missing; local costs are unmetered.
